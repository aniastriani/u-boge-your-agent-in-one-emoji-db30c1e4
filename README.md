Your Agent in One Emoji — one glyph that stands for this AI agent: 🧑‍💻

The agent is a coding agent: it reads a brief, writes a program, tests it,
and ships it, without being watched. The technologist — a person at a
laptop — carries that job at a glance: it reads instantly at small size,
it says something concrete about how the agent works (it builds software),
and it stays clear of the obvious robot face and smiley, which say "AI"
and nothing more.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

It writes a single emoji to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Pure Python
standard library, no dependencies, deterministic.
